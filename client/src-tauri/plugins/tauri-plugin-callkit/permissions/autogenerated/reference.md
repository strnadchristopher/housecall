## Default Permission

Lets the local webview ring, answer and end Housecall 1:1 calls through the iOS system call screen.

#### This default permission set includes the following:

- `allow-register`
- `allow-report-incoming`
- `allow-start-outgoing`
- `allow-connected`
- `allow-end`
- `allow-pending`
- `allow-mute`

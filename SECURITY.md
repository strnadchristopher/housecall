# Security policy

## Supported versions

Only the latest release is supported. Please update before reporting.

## Reporting a vulnerability

Report through GitHub private vulnerability reporting: open the repository's **Security** tab
and choose **Report a vulnerability**. Please do not open public issues or pull requests for
security problems.

## Known limitations

The encryption protocol is under development and has had no independent audit. Messages are
not end-to-end encrypted today; the server owner can read them. Do not rely on Housecall for
protection against the person who hosts it.

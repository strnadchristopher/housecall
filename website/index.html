Open HouseCall

You want your own place

HouseCall runs from one Docker Compose file on a computer you control. The software is free. The computer and its internet connection are the part you pay for.

Read the setup guide

housecall.chat is only the front door. Every community lives on its own host's server, and you choose which ones you walk into. An optional HouseCall account remembers your list of servers for you.

What's private, said plainly.

Your community lives on your host's server, so your host is the one you're trusting. Here is what they can and can't see.

One-to-one DMs in the apps
Messages and files are end-to-end encrypted once you both have security keys and your app has saved the other person's key. The host can see that you talk and when. They can't see what you say.
DMs in a web browser
Encrypted when you both have security keys, with a catch. A browser loads its chat code from the community's host, so a dishonest host could change it and read along. The installed apps don't get their code from the host.
Channels, group chats and calls
Not end-to-end encrypted. The host can read the messages and could listen to calls.
Outside review
Nobody outside the project has audited the encryption yet, and HouseCall is still pre-release software.

So pick a host you trust, or be the host. Read the whole privacy page
